# Object-Oriented-Programming
Repositório de projetos das disciplinas de Programação Orientada a Objetos 1 e 2, da UTFPR-CP, ministradas pelo Prof. Me. José Antonio Gonçalves e pela Profa. Dra. Gisele Alves Santana, respectivamente. POO 1 aborda um sistema de estoque de mangás para sebo, via terminal e interface gráfica. POO 2 envolve UML, bancos de dados e sistemas web.
